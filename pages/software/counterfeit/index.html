DTEK counterfeit detection system

Identifying counterfeit electronic components by comparing surface texture patterns // 2012

#HTML
#CSS
#3d-design

The DTEK system scans electronic components to analyze surface patterns and compare them to an original sample to identify counterfeit parts. I designed and developed the user interface that displays the results of four unique counterfeit tests done to help identify the electronic component as either original or counterfeit. This was my first software development project. I also helped with the 3-D design of the physical hardware. Read more about the DTEK system here
